## Eindopdracht Infrastructure and Cloud

## Beschrijving
Dit project bevat het resultaat van de verschillende opdrachten die uitgevoerd werden voor het vak Infrastructure and Cloud. Het omvat meerdere experimenten en toepassingen met onder andere Ansible, API’s, Docker, Jenkins, Flask, Python virtual environments (venv), unittests en Webex.

## Doel
- Inzicht verwerven in diverse DevOps-tools en -technologieën
- Begrijpen hoe services werken aan de hand van Python-code en Bash-scripts om taken te automatiseren
- Inzicht ontwikkelen in zelfsturend en professioneel handelen
